# Damophus Product Scope

Status: accepted on 2026-08-05.

## Purpose

Damophus 是一个专注于题库的思源插件。思源负责文档、数据库、同步和 Riff 调度，Damophus 负责题目识别、练习交互、作答事件、范围化复习，以及安全展示题库块身份。

## Retained Modules

- `lets-question-bank`
- `lets-block-attr`，仅保留题库身份属性显示

Dashboard、链接/引用转换、排版、快捷属性操作、列表视图转换、Memo，以及 EPUB、OCR、VoiceNotes、日记、随机题图、同步和未列出的工具模块均移除。删除模块时保留可追溯的上游 Git 历史，不复制无关实现到新模块。

## Version One

### Import and synchronization

1. 用户将已整理的 Markdown 粘贴或导入思源文档。
2. 用户手动触发“扫描当前文档”。
3. 插件展示新增、更新、推断和冲突预览。
4. 用户确认后，插件只补齐题目 IAL 并同步题目属性视图。
5. 缺少已绑定数据库时停止写入，不静默创建重复数据库。

插件可以初始化一个“题库系统”文档，其中包含题目属性视图和作答记录属性视图，也允许重新绑定现有属性视图。

### Practice scopes

- 默认以用户选择的整个文档为范围根节点。
- 插件读取标题树，自动识别专题、小专题、考点和题目。
- 用户可以选择任意标题块，只复习该块的全部后代题目。
- 自动识别不可靠时，展示标题树并要求用户选择范围根节点。
- 最近一次选择按文档 ID 和标题块 ID 保存；引用失效时重新选择。

每个范围支持顺序、随机、全部题、错题、连续待复习题和 Riff 到期题筛选。父专题递归包含所有后代小专题、考点和题目。

### Question types

- `single`
- `multiple`
- `true-false`
- `subjective`
- `group` 仅作为共享材料容器，子题独立作答

客观题由核心模块判定正确性，用户再独立评价掌握程度。主观题不做 AI 判分，由用户查看参考答案或评分要点后自行评分和评级。

### Answer interaction

- 作答时打乱选项顺序和临时显示标签。
- 用户请求揭晓后恢复题库源的原始顺序和原始选项 ID，再显示完整答案区；此时仍是尚未落库的临时结果。
- 作答事件记录展示顺序、用户选择的原始选项 ID、客观结果和掌握评级。
- 用户选择掌握评级后才最终写入作答事件。
- “误触，重新作答”在评级前恢复到作答状态，不写作答事件。
- 偶然答对但未掌握时，用户可以选择 Again 或 Hard。

### Flashcards

- 使用思源 Riff 维护调度状态。
- 使用快速制卡，不依赖历史兼容的卡包分类。
- Damophus 按文档、专题、考点和题目 ID 过滤到期题目并负责渲染。
- 建议评级只做高亮；用户点击任意评级后立即提交并进入下一题。
- 达到可配置的连续待复习次数时，可以自动加入快速闪卡；插件不自动移除卡片。

### Recovery

- 作答历史保存在作答记录属性视图的 detached rows 中，不创建单独历史文档。
- 作答事件不可变，聚合统计可以从事件重建。
- 首版提供带版本号的 JSON 导出和导入恢复。
- 日常数据保护仍依赖思源自身的同步和备份。

## Explicit Non-goals

- 不重复实现原 `siyuan-hqweay-go` 已提供的通用工具。
- 不实现网站账号、网站后端或网站作答同步。
- 不让插件改写题干、选项、答案或解析正文。
- 不创建独立错题文档或每次作答文档。
- 不使用卡包作为专题分类系统。
- 不进行 AI 主观题判分。
- 不在首版实现复杂组卷、排名、社交或多用户协作。
- 不让题库核心依赖思源 API，以免阻断未来网站复用。
