# Information Architecture: Damophus 题库设置

## Navigation Model

- **主导航**：沿用 Damophus 设置弹窗左侧插件分类，“题库”仍是唯一入口。
- **次级导航**：题库页头右侧提供页内快速导航；正文继续使用 disclosure 列表，不伪装成互斥标签页。
- **自适应**：空间充足时导航显示图标和文字；组件变窄时只显示图标，并保留名称提示。

## Content Hierarchy

1. 分组名称：说明用户正在控制哪类行为。
2. 分组摘要：帮助用户在展开前判断是否相关。
3. 当前分组设置：默认全部展开，仍允许按需单独收起。

## Settings Map

- 复习与闪卡：待复习阈值、自动制卡及 Hard/Again 阈值。
- 索引与扫描：自动同步、手动维护、自动扫描。
- 答题显示：标题、空答案块、原文样式、渲染方式、面包屑、标题嵌入范围。
- 计时：记录用时、看答案时暂停、用时对比位置。
- 原文答案遮罩：开关、遮罩样式与预览。

## Critical Flow

1. 用户进入“题库”设置。
2. 用户浏览五个分组的名称和摘要。
3. 用户点击页头导航快速滚动到目标分组，已收起的目标会自动展开。
4. 用户修改设置，继续沿用现有即时保存与预览行为。
5. 用户可再次点击当前分组收起，或直接展开另一组。

## Growth Plan

- 新设置必须先归入现有任务分组。
- 单组超过 7 项时再拆分，而不是增加新的导航层级。
- 只有设置总量明显超过当前规模时才增加搜索。
