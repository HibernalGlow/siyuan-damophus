# Damophus 题库工作台重组设计简报

## 用户与主任务

- 用户：高频刷题、组卷和模拟考试的法考学习者。
- 核心任务：进入题库后立即选择范围并开始答题，必要时再进入组卷或考试配置。
- 次要任务：查看进度与统计，维护扫描、索引和作答数据。

## 当前问题

1. 练习入口位于扫描和数据面板之后，首屏无法完成最常用任务。
2. 顶部“练习 / 统计”使用通栏分段控件，占据视觉中心但不能表达工作区层级。
3. 扫描摘要同时展示来源、进度、索引、考点关系和日志，所有信息权重接近。
4. 快速练习、跨文档组卷和考试分散在不同位置，组卷与考试需要进入用户不喜欢的二级界面。

## 设计目标

1. 练习配置和主操作在桌面与移动端首屏可达。
2. 题库工作区只保留一个高对比主操作，其余模式作为清晰的次级入口。
3. 扫描、同步、导入导出归入“准备与维护”，默认不阻断答题路径。
4. 组卷与考试在当前工作区原位展开，保留模式切换器，并采用统一的步骤、正文和动作区。
5. 宽度不足时，熟悉的导航和筛选控制仅显示图标，同时保留 `title` 与 `aria-label`。
5. 继续沿用思源主题变量、现有 Svelte 组件和 Lucide 图标，不引入新的视觉体系。

## 视觉方向

- 基础表面保持思源主题背景，主要通过间距、分组、细分隔线和轻微表面色差建立层级。
- 练习启动区是唯一强调面，使用主色窄边和清晰的大按钮，不增加装饰性卡片。
- 数据使用等宽数字与低饱和辅助色；系统维护信息默认收起。
- 圆角限制在现有 6-10px 范围，避免卡片套卡片。
