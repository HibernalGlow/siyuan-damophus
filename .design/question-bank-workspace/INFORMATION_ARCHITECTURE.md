# Information Architecture: Damophus 题库工作台

## Navigation Model

- **主工作区导航**：`答题`、`学习报告`。使用紧凑页签，不使用通栏分段按钮。
- **答题模式入口**：`快速练习`、`跨文档组卷`和`模拟考试`是同一工作区内可直接切换的三种模式，不跳转到二级页面。
- **维护入口**：扫描与索引、作答数据位于首屏练习区之后的“准备与维护”区域，采用 disclosure。
- **复杂模式**：组卷和考试在模式切换器下方原位展开，始终保留工作区导航、来源栏和模式切换器。

## Content Hierarchy

### 答题工作区

1. 来源上下文：当前文档标题、路径和源块 ID，供用户确认范围。
2. 未完成任务：存在时优先提供继续答题，避免丢失进度。
3. 快速练习配置：范围、题目顺序、选项顺序、筛选。
4. 主操作：开始练习。
5. 同页模式切换：跨文档组卷、模拟考试。
6. 进度概览：题量、已作答、未作答、待复习。
7. 准备与维护：扫描、索引、考点关系、导入导出和日志。

### 学习报告

1. 时间范围和排序。
2. 核心趋势与正确率。
3. 题目与考点明细。

### 跨文档组卷

1. 选择题源。
2. 检查并同步索引。
3. 设置抽题规则。
4. 预览并使用试卷。

### 模拟考试

1. 选择当前文档或已组试卷。
2. 设置题量、时间、顺序和评分规则。
3. 确认考试约束。
4. 开始考试。

## Critical Flows

### 快速答题

1. 用户进入题库，默认位于“答题”。
2. 用户在首屏确认来源和当前进度。
3. 用户调整范围、顺序或筛选。
4. 用户点击“开始练习”。

### 跨文档组卷

1. 用户在答题模式切换器选择“跨文档组卷”，页面原位切换内容。
2. 用户按步骤选择题源、确认索引、设置规则并预览。
3. 用户将冻结试卷用于练习或考试。

### 模拟考试

1. 用户在答题模式切换器选择“模拟考试”，页面原位切换内容。
2. 用户确认试卷来源和考试规则。
3. 用户点击“开始考试”。

## Naming Conventions

| Concept | Label in UI | Notes |
|---|---|---|
| 日常答题入口 | 答题 | 比“Practice”更贴近用户动作 |
| 数据视图 | 学习报告 | 比“统计”更能表达结果用途 |
| 单文档立即答题 | 快速练习 | 与组卷、考试区分 |
| 跨文档抽题 | 跨文档组卷 | 保留现有用户术语 |
| 有计时和提交规则的答题 | 模拟考试 | 明确区别于普通练习 |
| 系统准备操作 | 准备与维护 | 扫描、索引、导入导出的共同分组 |

## Component Reuse Map

| Component | Used on | Behavior differences |
|---|---|---|
| 工作区页头 | 答题、学习报告 | 当前页签高亮，保留关闭按钮 |
| 答题模式切换器 | 快速练习、组卷、考试 | 同页切换；窄屏只显示图标和可访问名称 |
| 工作流动作区 | 组卷、考试 | 次要操作靠左，主操作靠右 |
| Disclosure 面板 | 扫描与索引、作答数据 | 默认收起，错误或用户操作时展开 |
