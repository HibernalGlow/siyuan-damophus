# Damophus

> 自用的思源笔记题库插件，主要服务于个人法考学习流程。

Damophus 不是通用工具箱，也不试图替代思源、Riff 或既有的闪卡插件。它只实现我在题库整理、范围练习、错题复习和可恢复作答中需要，而现有插件通常没有同时覆盖、或无法在思源中安全组合的能力。仓库公开用于参考；功能方向、兼容范围和维护节奏均以自用需求为准。

题库功能遵循仓库内已经接受的产品范围和数据契约；插件壳继续使用 `PluginRegistry` 与 `SubPluginBase` 自动发现子插件。

## 为什么有这个插件

Damophus 的重点是让 Markdown 题库可以在思源中长期使用，而不把练习状态混入原题或依赖另一套卡包体系：

- **题源保持可移植**：Markdown 与 IAL 保存题干、选项、答案、解析和稳定题目 ID；插件不会改写这些正文内容。
- **索引过程可审查**：扫描先展示推断、冲突、将要补齐的题库属性和属性视图修复项，用户确认后才写入。
- **练习记录可重建**：每次评级形成不可变作答事件，错题、复习状态和统计都从事件派生，而不是反写题目。
- **范围与调度分工明确**：Damophus 用文档、标题专题和稳定题目 ID 组织范围；思源 Riff 只负责闪卡调度。
- **练习可以安全续做**：未完成会话单独保存，支持暂停、恢复、题源变更协调、并发窗口保护和诊断导出。
- **贴合法考题型**：支持单选、多选、不定项、判断、主观题和共用材料题组，并保留选项原始 ID 以确保乱序后仍能正确判题。

## 当前模块

- `lets-question-bank`：题库初始化与重连、扫描预览与确认、范围练习、Riff 到期复习、作答记录导入导出和会话恢复。
- `lets-block-attr`：仅显示安全的题库身份属性，默认横向展示 `qb-id` 与 `qb-type`，空间不足时自动换行；设置页可预览并自定义标签与样式，答案属性始终隐藏。

Dashboard、链接/引用转换、排版、快捷属性操作、列表视图转换、Memo，以及 EPUB、OCR、VoiceNotes、日记、随机题图、同步等旧模块均不属于 Damophus 产品范围。需要这些通用工具时继续使用原 `siyuan-hqweay-go` 插件。

## 题库

题库内容以 Markdown 与 IAL 为事实来源，作答记录使用不可变属性视图事件，Riff 只负责调度，Damophus 负责扫描、练习和渲染。插件支持初始化题库系统文档、扫描预览与确认、专题范围、顺序/随机练习、错题与待复习筛选、客观题和主观题、快速闪卡，以及版本化 JSON 导入导出。

## 开发

```sh
pnpm install
pnpm dev
pnpm check
pnpm test
pnpm test:browser
pnpm test:smoke
pnpm build
pnpm test:package
```

`pnpm dev` 会启动独立的本地题库预览页（默认 `http://127.0.0.1:5173/`），使用内存模拟数据，不连接或写入思源。预览页支持桌面/手机宽度、浅色/深色主题和中英文切换。需要监听构建并部署到思源插件目录时使用 `pnpm dev:plugin`。

构建会自动生成翻译聚合文件与 `package.zip`；这些生成物不进入 Git。子插件约束、i18n 规则和生命周期要求见 [AGENTS.md](AGENTS.md)。
